# Marine Oil Spill Detection & Reporting with Gemma 4

[![Kaggle](https://img.shields.io/badge/Kaggle-Gemma%204%20Good%20Hackathon-blue)](https://www.kaggle.com/competitions/gemma-4-good-hackathon)

## 🚀 Overview

This project is an end-to-end pipeline for **automated oil spill detection** from SAR satellite imagery and **intelligent report generation** using **Gemma 4**. It was developed for the **Gemma 4 Good Hackathon** on Kaggle, aiming to assist maritime authorities and environmental agencies in rapid oil spill response.

The system combines:

- **Computer vision** – three CNN models (ResNet50, EfficientNet-B0, MobileNetV3-Large) trained on Sentinel‑1 SAR data. An **uncertainty‑weighted ensemble** and **knowledge distillation** produce a lightweight yet accurate MobileNetV3‑Small model.
- **Geospatial reasoning** – distance to coastline (geodesic), proximity to AIS vessels within 6 hours and 2 nautical miles.
- **LLM‑powered reporting** – Gemma 4 (4B instruction‑tuned) generates concise, human‑readable reports from the detection and geospatial context.

> ✅ **Key outcome:** Distilled MobileNetV3‑Small achieves **90.7% accuracy** and **86.7% F1** while being fast enough for edge deployment. The ensemble reaches **97.7% accuracy** (test set). Gemma 4 reports include distance to coast, potential polluter MMSI, and safety assessment.

## 🚀 Usage

### Option A: Full pipeline (detection + Gemma report)

Run the cells in `gemma-oil-detect.ipynb`. The notebook:

1. Loads the distilled student model and Gemma 4.
2. Iterates over test images (in `Samples/`).
3. For each image:

   * Predicts oil spill presence.
   * If positive, computes distance to coast and finds nearby vessels.
   * Generates a short report using Gemma 4.

   **Example report:**

   ```plaintext
   该坐标[-89.8148, 29.2767]有泄漏，距离海岸线2.30海里，小于20海里，可能的泄露船只编号：[816035178]
   ```

   ### Option B: Training from scratch

   Run `model_prepare_kaggle.ipynb` (Kaggle GPU recommended). It will:


   * Load and split the dataset (train/val/test).
   * Train three individual models with weighted sampling and focal loss.
   * Build an uncertainty‑weighted ensemble.
   * Distill the ensemble into a lightweight student model.
   * Save all `.pth` files to `best_models/`.

## 🌊 Context Integration

The decision tool (`OilSpillDecisionTool`) provides:

* **Distance to coast** – computed using nearest‑point interpolation on a global coastline shapefile (EPSG:4326).
* **Vessel detection** – queries a sample AIS dataset for any ship that passed within **2 nautical miles** during the **last 6 hours** before the incident time.

These data are then passed to Gemma 4 via a **structured prompt** that elicits a concise, factual report – no hallucinated coordinates or irrelevant details.
